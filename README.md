**[Civitas](https://github.com/DivyanshuDX/Civitas)** — A blockchain-based identity and consent platform on Algorand. Three separate smart contracts (whitelisting, consent lifecycle, identity-NFT issuance) instead of one monolith, so a bug in one piece can't compromise the others — deployed contracts can't just be patched later. End-to-end encryption means raw identity data is never stored server-side.

**[Xelt VPN](https://github.com/DivyanshuDX/Xelt-VPN)** — A subscription-free VPN that settles every session as an on-chain micropayment instead of a monthly plan, behind an encrypted WireGuard tunnel.

**Smaller builds:** a Python/Tkinter [Student Database Management System](https://github.com/DivyanshuDX) with a normalized MySQL schema, and **Toodle**, a voice-controlled assistant using speech recognition.
